# 수학탐정단: 암호 연구소 탈출 미션 v2

## 개요
수학체험전 부스용 웹 기반 암호 방탈출 미니게임입니다. 
초등학생들이 시저 암호, 좌표 암호, 이진법 원리, 수열 규칙 등을 직접 해결하면서 수학적 개념에 대한 흥미를 유발할 수 있도록 구성되었습니다.

## 주요 기능
- **탐정 이름 등록**: 최대 12자의 한글/영문 탐정 이름 입력 기능 (미입력 시 '수학탐정')
- **3단계 난이도 선택**: 쉬움(초등 3~4학년), 보통(초등 4~6학년), 어려움(초등 5~6학년 이상)
- **랜덤 문제 자동 출제**: 난이도마다 4가지 유형(시저 암호, 좌표 암호, 이진수 암호, 수열 금고)의 문제 은행(각 10개씩)에서 랜덤 추출
- **암호 자동 생성 엔진**: 정답 단어를 기반으로 시저, 좌표, 이진수 형태의 문제를 프로그램에서 실시간 자동 생성하여 정답 정합성 보장
- **진행 상태 & 타이머**: 0.1초 단위 흐름 제어로 타이머 가동(성공 시점까지 기록), 진행률 바 실시간 갱신
- **성공 인증서**: 완료 난이도와 소요 시간을 기입하고 `window.print()`를 지원하는 인쇄용 레이아웃 최적화
- **명예의 전당 (TOP LIST)**: 난이도별 TOP 10 실시간 랭킹 시스템 (브라우저 `localStorage` 연동, 초기화 및 confirm창 기능 포함)
- **부드러운 UI/UX**: 글라스모피즘 스타일, 네온 빛 이펙트, 오답 시 오답 사운드나 격렬하게 흔들리는(shake) 애니메이션 피드백 적용

## 실행 방법
1. `index.html` 파일을 브라우저(Chrome, Edge 등)로 직접 엽니다.
2. 탐정 이름을 입력합니다.
3. 알맞은 난이도를 선택합니다.
4. 1~4단계 미션의 암호를 차근차근 풉니다. (막히는 경우 💡 힌트 보기 버튼 활용)
5. 마지막 금고까지 해결한 뒤 성공 인증서를 인쇄하거나 TOP LIST 기록을 확인합니다.

## 배포 방법
1. 빌드 명령(build command)이나 서버 설정이 전혀 필요 없는 순수 정적 웹앱(Static Web App)입니다.
2. [Netlify](https://www.netlify.com/)에 가입한 뒤 프로젝트 폴더(`math-cipher-escape/`)를 그대로 드래그 앤 드롭하여 업로드하면 즉시 온라인 무료 배포가 완료됩니다.
3. GitHub 저장소에 업로드하고 Netlify와 연동하면 소스코드 커밋 시 자동 업데이트 배포도 지원합니다.
