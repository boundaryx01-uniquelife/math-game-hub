방법 1. 앱으로 설치 추천

한 번 설치해 두면 인터넷 없이도 홈 화면 아이콘으로 바로 열립니다. 태블릿(iPad, 갤럭시탭 등)에서는 이 방법을 쓰세요.

  1. 인터넷이 되는 곳에서 이 사이트를 엽니다. (QR 코드 또는 주소 입력)
  2. 위 “오프라인 준비”가 ✅ 준비 완료로 바뀔 때까지 잠시 기다립니다. (보통 수 초)
  3. 아래 방법으로 홈 화면에 추가 / 설치합니다.
  4. 와이파이를 끄고(비행기 모드) 설치된 아이콘으로 열어 정상 실행되는지 꼭 확인합니다.

안드로이드 (Chrome)

  1. 오른쪽 위 ⋮ 메뉴 → 앱 설치 (또는 홈 화면에 추가)
  2. 위의 “앱으로 설치하기” 버튼이 보이면 그것을 눌러도 됩니다.

아이패드 / 아이폰 (Safari)

  1. Safari로 엽니다. (다른 브라우저 앱에서는 홈 화면 추가가 제한될 수 있습니다)
  2. 주소창 옆 공유 버튼(□↑) → 홈 화면에 추가 → 추가
  3. 설치 버튼은 Safari에서 나타나지 않습니다. 위 방법으로 직접 추가하세요.

윈도우 / 크롬북 (Chrome, Edge)

  1. 주소창 오른쪽의 설치 아이콘(⊕ 또는 모니터 모양) 클릭 → 설치
  2. 또는 ⋮ / … 메뉴 → 앱 및 기능(또는 저장 및 공유) → 이 사이트를 앱으로 설치
설치하지 않고 브라우저 탭으로만 써도, 한 번 “오프라인 준비 완료”가 되었다면 같은 브라우저에서 오프라인으로 열립니다. 다만 브라우저가 저장 공간을 정리하면 사라질 수 있으니 설치를 권장합니다.

방법 2. 내려받아 실행 PC·크롬북

  1. 인터넷이 되는 곳에서 압축 파일을 내려받습니다:
    https://github.com/boundaryx01-uniquelife/math-game-hub/archive/refs/heads/main.zip
  2. 압축을 풉니다. (폴더 안에서 바로 열지 말고 꼭 “모두 압축 풀기”)
  3. math-game-hub-main/math-game-hub/index.html 을 Chrome 또는 Edge로 엽니다.
알아둘 점
  • 이 방식은 PC·노트북·크롬북에서 현실적입니다. 아이패드/안드로이드 태블릿은 내려받은 HTML 파일을 브라우저에서 여는 과정이 번거롭고 제한이 많아 방법 1을 권장합니다.
  • 파일로 직접 열면(file://) “앱 설치/오프라인 저장” 기능은 쓸 수 없지만, 파일 자체가 내 기기에 있으므로 인터넷 없이 열립니다.
  • Chrome에서는 파일 주소로 열면 보안 정책상 data/cipher_bank.json 불러오기가 막힙니다. 암호 게임은 내장 문제은행(또는 data/cipher_bank.js)으로 대신 동작하므로 문항 수가 적을 수 있습니다.
  • 순위 기록은 열 때마다 같은 파일 경로로 열어야 유지됩니다. 폴더를 옮기거나 다른 브라우저로 열면 기록이 보이지 않을 수 있습니다.

순위 기록은 어디에 저장되나요?

  • 순위는 이 태블릿(이 브라우저) 안에만 저장됩니다. 서버로 전송되지 않습니다.
  • 다른 태블릿과 공유되지 않습니다. 태블릿마다 순위가 따로입니다.
  • 브라우저의 “사이트 데이터/인터넷 사용 기록 삭제”를 하거나 시크릿(비공개) 창에서 플레이하면 기록이 사라집니다.
  • 같은 기기라도 브라우저가 다르면 기록이 따로입니다. (예: Chrome 탭과 Safari 앱) 같은 브라우저, 같은 주소(주소가 바뀌면 다른 저장소)에서 연 탭과 설치된 앱은 보통 기록을 함께 씁니다. 단, iPad 홈 화면 앱은 Safari 탭과 저장소가 분리될 수 있으니 한 가지 방법만 쓰세요.
  • 그래서 행사 전·후에 아래에서 백업 파일을 내려받아 두는 것을 권장합니다.

문제가 생겼을 때

  • “오프라인 준비”가 계속 안 끝나요 → 와이파이가 연결된 상태에서 페이지를 새로고침하고 1분 기다립니다. 그래도 안 되면 브라우저를 완전히 종료한 뒤 다시 엽니다.
  • 업데이트된 내용이 안 보여요 → 인터넷이 되는 곳에서 “새 버전 확인”을 누르고 앱을 한 번 닫았다 엽니다.
  • 이 페이지의 “오프라인 준비”가 “지원 안 됨”으로 나와요 → 파일로 열었거나(file://), 주소가 https://가 아닌 경우입니다. 방법 1은 https:// 주소에서만 됩니다.
