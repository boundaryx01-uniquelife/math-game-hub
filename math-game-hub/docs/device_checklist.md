## iPad (Safari)
- [ ] Safari로 사이트 접속 → 공유 → "홈 화면에 추가" → 아이콘과 이름이 보임
- [ ] 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열림
- [ ] 허브 아래 오프라인 상태가 "준비 완료"로 바뀔 때까지 기다림
- [ ] 비행기 모드로 바꾼 뒤 앱을 완전히 닫고 다시 실행 → 허브가 열림
- [ ] 비행기 모드에서 게임 4종을 각각 끝까지 진행 → 기록이 명예의 전당에 남음
- [ ] 세로·가로로 돌려도 버튼이 잘리지 않음
- [ ] 한글 줄바꿈이 단어 중간에서 끊기지 않음
- [ ] 수열 게임 숫자판, 확률 게임 슬라이더가 손가락으로 잘 눌림
- [ ] 소리(효과음)가 남, 무음 스위치 상태 확인

## Android 태블릿 (Chrome)
- [ ] Chrome 메뉴 → "앱 설치" 또는 "홈 화면에 추가" → 설치됨
- [ ] 설치한 앱이 전체 화면으로 열림
- [ ] 오프라인 "준비 완료" 확인 후 비행기 모드에서 앱 재실행 → 허브가 열림
- [ ] 비행기 모드에서 게임 4종 진행·기록 저장
- [ ] 세로·가로 회전, 한글 줄바꿈, 터치 확인(위와 같음)
