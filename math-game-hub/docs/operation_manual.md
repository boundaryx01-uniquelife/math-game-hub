# 코드 브레이커 & 갈톤 메이커 부스 운영 매뉴얼

## 1. 부스 개요
* **부스명**: 코드 브레이커 & 갈톤 메이커
* **대상**: 초등 5~6학년 및 중학생
* **목표**: 암호 방탈출과 3D 프린터 갈톤보드 확률 실험을 통한 수학적 규칙성과 자료의 가능성 직관적 체득

---

## 2. 부스 배치 및 동선 가이드

```
[부스 입구 (QR 코드 스캔)]
       ↓
[Zone A: 웹게임 체험 태블릿]
  - 암호 연구소 탈출 미션 (3~6분)
  - 1인 1태블릿 또는 2인 1조
       ↓
[Zone B: 3D 갈톤보드 실험대]
  - 구슬 30~50회 낙하 실험
  - 결과 기록지에 히스토그램 스티커 부착
       ↓
[부스 출구]
  - 수학탐정 인증 스탬프 / 기념품 수령
```

---

## 3. 현장 운영 팁

1. **오프라인 환경 대비**:
   - 본 웹앱은 인터넷이 연결되지 않은 로컬 환경(파일 직접 실행 또는 로컬 웹서버)에서도 완벽히 동작합니다.
2. **태블릿 키보드 설정**:
   - 좌표 및 시저 암호는 영문 대문자 입력이 편리하도록 영문 자판 기본 설정을 권장합니다.
3. **랭킹 초기화**:
   - 매 타임(예: 1시간 단위) 또는 오전/오후 세션이 바뀔 때 명예의 전당 하단의 `[기록 초기화]` 버튼을 눌러 새 라운드를 시작할 수 있습니다.
